## Arpit Jain Best Researcher Scholarship (AJBRS)

Source for https://scholarship.arpit-jain.com, built by GitHub Pages (plain Jekyll, no theme).

- Add a year: a new entry at the top of `_data/recipients.yml`. The home page's numbers are counted from it.
- Pages: `index.html`, `recipients.html`, `how-to-apply.html`, `contact.html`; one layout in `_layouts/default.html`.
- Preview: `bundle install && bundle exec jekyll serve`.
